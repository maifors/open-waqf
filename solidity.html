How Average Joe Can Write Simple Solidity Contracts

Solidity is the programming language used to write smart contracts on blockchains like Ethereum. If you’re not a programmer, don’t worry! This guide will walk you through how you can try writing and deploying a simple contract using an easy online tool called Remix IDE.

Step 1: Open Remix IDE

Remix is a free, browser-based Solidity editor and compiler. You don’t need to install anything.

Open Remix IDE

Step 2: Write a Simple IOU Contract

Copy and paste the following Solidity code into Remix’s editor panel (usually on the left side): 

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleIOU {
    address public lender;
    address public borrower;
    uint public amount;

    constructor(address _borrower, uint _amount) {
        lender = msg.sender;       // person who creates the contract is the lender
        borrower = _borrower;
        amount = _amount;
    }

    function markAsPaid() public {
        require(msg.sender == borrower, "Only borrower can mark as paid");
        amount = 0;
    }
}

Step 3: Compile the Contract

In Remix, click the Solidity Compiler tab (the one with the "sol" icon), then click Compile SimpleIOU.sol. If there are no errors, you’re ready to deploy!

Step 4: Deploy the Contract

Switch to the Deploy & Run Transactions tab (the Ethereum icon). Make sure the environment is set to JavaScript VM (this runs the contract in your browser for testing).

In the deployment section, enter:

  • _borrower: Enter an Ethereum address (you can pick one from the dropdown accounts Remix provides)
  • _amount: Enter the amount owed (e.g., 100)

Then click Deploy. Your contract is now live in the browser!

Step 5: Interact with Your Contract

After deployment, Remix will show your contract instance under Deployed Contracts.

  • Click lender or borrower to see the addresses.
  • Click amount to see how much is owed.
  • If you want to mark the IOU as paid, select the borrower account in Remix’s account dropdown, then click markAsPaid. This sets the amount to zero.

Why This Matters

This simple contract shows how you can create a digital agreement that records a debt between two parties, without needing a middleman like a bank or lawyer. Once deployed on a real blockchain, it becomes a transparent and tamper-proof record.
